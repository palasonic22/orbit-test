# ADR-002 — Raise Default Deposit Rate to 30% & 24h Free Cancellation

- **Scope:** orbit-test
- **Status:** superseded
- **Supersedes:** ADR-001
- **Superseded-by:** ADR-003
- **Date:** 2026-11-15T00:00:00Z

## Context
A 20% deposit produced excessive last-minute cancellations in the synthetic test baseline.

## Decision
Set the default booking deposit rate to **30%** (`depositPercent = 30`) and document a **24-hour free cancellation window**.
